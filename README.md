## 기능 요구 사항 정리

입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

- 입력된 문자열은 구분자와 숫자를 가진다.
- 구분자를 기준으로 잘라서 숫자를 추출한다.
- 구분자는 쉼표(,), 콜론(:)이 존재하고, 추가적으로 커스텀할 수 있다.
- 커스텀 구분자는 문자열 앞부분에 "//"와 "\n" 사이에 위치하는 문자가 커스텀 구분자이다.
    - 예를 들어 "//;\n1;2;3" 이라면 커스텀 구분자는 세미콜론(;)이며 결과는 6이다.
- 구분자와 커스텀 구분자는 혼용할 수 있다.
    - "//;\n1;2,3"과 같이 세미콜론(;)과 쉼표(,)가 구분자로 사용되었다.

## 구현할 기능 목록

- [x] 사용자
    - [x] 구분자와 양수로 구성된 문자열

- [x] 문자열 계산기
    - [x] 구분자 또는 커스텀 구분자를 추출한다.
        - 구분자는 쉼표(,)와 콜론(:)이 존재한다.
        - 커스텀 구분자는 문자열 앞부분에 "//"와 "\n" 사이에 위치한다.
    - [x] 구분자를 기준으로 숫자를 추출한다.
        - 숫자는 양수이다.
    - [x] 숫자를 더하여 결과 값을 도출한다.

## 예외 상황

- [x]  숫자가 음수인 경우
    - 음수('%d')는 계산할 수 없습니다.
- [x]  숫자가 아닌 문자인 경우
    - 입력값 '%s'는(은) 유효한 숫자가 아닙니다.

## 테스트 코드

- Number
    - [x]  정상적으로 성공 (숫자 초기화)
    - [x]  0을 입력하는 경우 정상 생성
    - [x]  빈 문자열을 입력하는 경우 예외 발생
    - [x]  공백 문자만 있는 경우 예외 발생
    - [x]  null을 입력하는 경우 예외 발생
    - [x]  숫자가 음수일 경우 예외 발생
    - [x]  숫자가 아닌 문자인 경우 예외 발생

- Numbers
    - [X]  정상적으로 덧셈 성공 (sum메소드)
    - [x]  숫자 배열이 비어있을 때 sum 호출 시 0 반환
    - [x]  숫자가 하나만 있을 때 sum 호출 시 해당 숫자 반환

- ExpressionParser
    - [x]  기본 구분자와 커스텀 구분자를 파싱해서 정상적으로 split 성공
    - [x]  기본 구분자 (, 또는 :)만 있을 경우 정상 split
    - [x]  커스텀 구분자만 있을 경우 정상 split

- Calculator
    - [x]  정상적으로 덧셈 성공 (add메소드)
    - [x]  입력값이 null 또는 빈 문자열일 경우 0 반환
    - [x]  숫자 하나만 입력할 경우 해당 숫자 반환
